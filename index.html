How the hosted version works

1 · Open a dashboard

The starter database is bundled with the page, so the tables, ratings, predictors and backtests work immediately — even before anything new is captured.

2 · Connect the relay (once)

Bet9ja's feeds do not allow direct browser requests from another domain. A tiny free relay (included in proxy/worker.js) forwards only the Bet9ja hosts and adds the missing CORS header. Paste its URL in the Connect live capture pill.

3 · Keep the tab open

While a dashboard is open it captures new rounds automatically — every ~3 minutes for Zoom, ~20 seconds for League Plus. Data is stored in this browser's IndexedDB; export a backup from Settings whenever you like.

Honest notes

These are statistical tools, not a guaranteed income. Bet9ja keeps a margin on every price — roughly 5% on 1X2, GG/NG and over/under, and much more on correct score. The backtests in each dashboard show what the engines actually did on recorded data; trust those numbers, not the marketing. Stake only what you can afford to lose. 18+.

Live in-play is not part of the hosted build: it read the Bet9ja page's own push feed through an injected content script, which a normal website cannot do. Everything else — history, tables, ratings, predictions, value, slips and backtests — is here.
